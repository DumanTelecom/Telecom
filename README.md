# Учёт инсталляторов

Веб-страница с таблицей и графиком по инсталляторам (Ершов А, Рашитбек Д, Аскаров):
наряды, установки, замены, снятие, вызов инсталлятора и автоматический расчёт оплаты.

## Цены (меняются прямо на странице)
- Установка — 7000
- Замена — 3000
- Вызов инсталлятора — 1000
- Снятие — 500

## Возможности
- Редактирование записей в таблице, добавление и удаление
- Фильтр по инсталлятору и датам
- График: количество / оплата
- Данные сохраняются в браузере (localStorage)

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages:
**Settings → Pages → Deploy from a branch → main / (root)**.
